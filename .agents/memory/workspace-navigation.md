---
name: Workspace navigation
description: Avoid confusing this workspace's private app with public profile listings.
---

Do not direct the user through assumed Projects or Remix menus without checking their actual interface. Their sidebar did not match those documented directions.

**Why:** Repeated menu guesses led the user to a public profile with no public apps and made them believe the private app was missing or incorrectly configured.

**How to apply:** Verify the artifact registry and deployment metadata first. Distinguish the project workspace, app Preview, and private published URL. A public profile is not an inventory of private apps; do not request publication to make a private app discoverable.
