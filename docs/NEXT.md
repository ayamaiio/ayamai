# Next

Where the project is going, in prose. No checkboxes, no numbers — the plan store
holds what someone is about to do; this page holds what we believe the work is
about. If an item here becomes real, it gets an `ayamai plan add` with an
acceptance line and disappears from this page.

## The foundation is done

One door, one design kit, eight products behind it, a release gate that cannot
ship by accident, and a public page that says what we are. That was the first
year's work compressed into a month: the shape exists.

What we do not have yet is **evidence that it holds up outside this machine**.

## 1. It has to run where I am

The platform is currently proven on one desktop, next to the thing that built it.
A mac mini, a laptop, a TV in the living room — each of them is a different kind
of proof: a different OS, a different GPU, a different reason to open it.

If installing on the second machine is not boring, the first machine is not done.

## 2. It has to survive me

One vault, one copy, no verification that it can be read back without the network.
The product already works; this is about it still working after a disk dies. The
boring half of local-first is the half that earns the claim.

## 3. It should tell me what is stale

Right now I know what is running. I do not know what is *neglected*: which project
has not been touched in three weeks, which one has open work nobody claimed, which
one is on fire. Every surface asks me to look; none of them answers.

## 4. The fork question

yoru's browser story — fork Chromium, wrap it in Electron, or stay on the web — has
been an item on a list for a month. It is a decision, not a task: it wants one page
of tradeoffs and a recommendation, then it is over.

## 5. The fork we already made

Azahar is forked, pinned, and has no diff of its own. A fork with no patches is a
bookmark. The first patch is what makes it ours.

## What this page is not

A roadmap with dates. A promise to build all five. A place to park every idea —
ideas go in seiri's inbox, tasks go in the plan store, and this page carries only
what survives being argued about.
