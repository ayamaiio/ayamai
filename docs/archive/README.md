# Archive

These files described earlier versions of the product. They are kept for the record and **are not maintained**.

| folder | what it was |
|---|---|
| `media-era/` | ayamai as a private invite-only media app: curator, edge authorization, invites, previews, labeling, deployment |
| `product-handbook/` | the product handbook of that era: vision, how we work, process, operations, initiatives, ideas |
| `plan/` | the pre-foundation board: 18 items and 12 ideas, retired in one pass on 2026-11-02 |
| `platform-era/` | the first architecture note and the WSL runbooks, before the door, gehirn and the catalog |

The retired board is readable at
[plan/2026-11-02-pre-foundation.md](plan/2026-11-02-pre-foundation.md); its machine
copy is beside it, and every item is still revivable with `plan set <id> --status todo`.

The current canon is [../PRODUCT.md](../PRODUCT.md), [../ARCHITECTURE.md](../ARCHITECTURE.md) and [../OPERATIONS.md](../OPERATIONS.md). Nothing forward-facing should link here except for history.

## Still in use (do not archive)

Some media-era directories are not history: `extensions/browser-capture/` holds the
capture protocol yoru uses, `infrastructure/shared-media-edge/` holds the edge worker
and its canaries, and `apps/magi/` runs storybook. They are listed here so nobody
deletes them thinking they are dead.
